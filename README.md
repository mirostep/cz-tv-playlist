# Czech TV Playlist 🇨🇿

**Czech Republic IPTV playlist with channel logos**

A collection of Czech television channels in M3U format, with unified 256 × 256 px PNG channel logos hosted on GitHub.

## 📺 Playlist

**Direct M3U playlist URL:**

`https://raw.githubusercontent.com/mirostep/cz-tv-playlist/main/cz_tv_github.m3u`

Use this URL to add the playlist to your IPTV player.

## Features

- Czech television channels
- 108 channel logos in PNG format
- Unified 256 × 256 px logo dimensions
- Channel logos hosted on GitHub
- Direct M3U playlist link
- Compatible with VLC and IPTV players supporting M3U playlists

## Compatible players

- VLC Media Player
- Televizo
- Other IPTV players supporting M3U playlists

## Installation

1. Open your IPTV player.
2. Choose the option to add a playlist by URL.
3. Copy and paste the M3U link above.
4. Save and load the playlist.

## Repository structure

- `cz_tv_github.m3u` – M3U playlist
- `logos/` – channel logos in PNG format

## Important information

This repository provides playlist links and channel logos. It does not host or operate television streams.

Stream availability depends on the original providers and may change or stop working at any time.

# Český televizní playlist 🇨🇿

**IPTV playlist českých televizních stanic s logy**

Soubor M3U obsahující výběr českých televizních stanic. Jednotná loga stanic jsou uložena na GitHubu ve formátu PNG o rozměrech 256 × 256 px.

## 📺 Playlist

**Přímý odkaz na M3U playlist:**

`https://raw.githubusercontent.com/mirostep/cz-tv-playlist/main/cz_tv_github.m3u`

Tento odkaz lze vložit přímo do IPTV přehrávače.

## Vlastnosti

- České televizní stanice
- 108 log stanic ve formátu PNG
- Jednotné rozměry log 256 × 256 px
- Loga uložená na GitHubu
- Přímý odkaz na M3U playlist
- Podpora přehrávačů VLC a IPTV aplikací

## Podporované přehrávače

- VLC Media Player
- Televizo
- Další IPTV přehrávače podporující formát M3U

## Návod k použití

1. Otevři IPTV přehrávač.
2. Vyber možnost přidání playlistu pomocí URL adresy.
3. Vlož výše uvedený odkaz na M3U playlist.
4. Ulož a načti playlist.

## Struktura repozitáře

- `cz_tv_github.m3u` – televizní playlist
- `logos/` – loga televizních stanic ve formátu PNG

## Důležité informace

Tento repozitář poskytuje odkazy na playlist a loga televizních stanic. Neprovozuje ani nehostuje televizní streamy.

Dostupnost streamů závisí na původních poskytovatelích a může se kdykoliv změnit nebo ukončit.
